# Going first, with and without Draft (2026-10-15)

Eggbog mode, computer mirror matches, game at main be29cca. `firstsim.js crazy <level> 5000 base [fx]`, 2 runs per cell, raw JSON in `results-first-draft/`.
"Without" = today's defaults minus Draft. Margin of error about ±1 point per 10,000 games.

| Level | With Draft (today) | Without Draft | Change |
|---|---|---|---|
| Easy | 49.8% | 51.4% | -1.6 |
| Normal | 49.0% | 52.1% | -3.1 |
| Hard | 49.2% | 53.7% | -4.5 |

Draft pulls the first player from ~52-54% down to ~49%. Likely reason (inferred, not measured): the starter holds the extra Egg card, so the second player more often has the smaller hand and gets Draft's bonus card.
